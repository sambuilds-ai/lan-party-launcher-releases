# LAN Party Launcher v0.48.7

## Changes

- Use icons in the desktop top bar, add a one-icon theme switch, and drop the search glow
- Keep each look's own focus indicator on non-search controls
- Move channel actions into a right-click menu and dock voice controls above the user card
- Keep voice failures and controls in the dock on every page
- Add start, stop, restart and settings controls for LAN services in the desktop GameSpy page
- Retry the failed service action after a partial stop or restart
- Keep ICQ running while the LAN Party app is open
- Mount Chat only when a surviving call needs it, and fix integration regressions
- Stop the startup voice check once native voice answers idle
- Show one tooltip on voice icons instead of two
- Keep Leave final after a voice failure and return focus after channel dialogs
- Show a native voice timeout while the microphone request is still pending
